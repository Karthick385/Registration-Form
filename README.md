# Registration Form 

## Project Overview
This project is a simple web application built using HTML, CSS, and JavaScript. It includes:

- A Registration Form with real-time validation
- A Text Area with a live character counter

---

# Features

## Registration Form Validation
The form contains:
- Name
- Email
- Password

### Validation Rules
- Name field cannot be empty
- Email must be in a valid format
- Password must contain at least 6 characters
- Error messages appear in real time
- Submit button stays disabled until all fields are valid

---

## Character Counter
The text area includes:
- Real-time character counting
- Maximum character limit display
- Remaining character count
- Prevention of typing beyond the limit
- Warning message when limit is reached

Example:
150/200 characters
